03 / EXACT COLLISION

Two different originals.
One identical output.

One all-white source and another with a single missing pixel yield the same mandala at N=3, 7 and 16. At N=1, they're distinguishable.

No decoder, no matter how sophisticated, can infer which source was used from those equal observations alone.

04 / THE LIMIT

Folding ≠ revealing.

Rotation and reflection move evidence around. The max operation suppresses all nonwinning contributions. Provenance reveals which branch won, not what the other branches carried.

Inverse rendering can select a plausible source. Identifiability requires enough independent measurements to rule out alternatives.
